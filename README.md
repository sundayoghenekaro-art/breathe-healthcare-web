# Breathe Healthcare Web

A redesigned landing page for **Breathe by TrikaHealth**.

## Positioning

**Your health. Connected.**

The landing page presents Breathe as a connected digital healthcare ecosystem rather than only a telemedicine consultation product.

## Included

- Patient-focused hero and CTA
- Connected healthcare ecosystem
- Consultation → assessment → investigation → treatment → follow-up journey
- Virtual consultation
- Electronic health records
- Pharmacy and delivery
- Laboratory services
- Referral / physical care
- AI health assistant
- Individuals, families, corporates, HMOs and government positioning
- Privacy, controlled access and audit messaging
- Pricing / free trial section
- Responsive mobile-first layout

## Run locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
